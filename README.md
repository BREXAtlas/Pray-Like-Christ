# Pray Like Christ

**Pray Like Christ | Make Him Known** is a free, accessible prayer-learning website based on Lawrence McGaffie's book *Pray Like Christ*.

## Website

The root `index.html` is a self-contained website, with its CSS, JavaScript, and the three supplied images embedded. No build process or server is needed.

It provides:
- A central, interactive guide through the Lord's Prayer (Matthew 6:9–13).
- Ten expandable prayer sections with introductory teaching grounded in the opening manuscript teaching.
- Practical examples to help someone pray in everyday language.
- Connections between the prayer and all 29 titled teachings in the manuscript.
- A guided prayer walkthrough and searchable lessons.
- A mobile-friendly, accessible layout.

The website's name is **Pray Like Christ**. "How We Pray" is the name of one manuscript teaching, not the website.

## Preview

Open `index.html` locally in a browser.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the **main** branch and **/(root)**, then Save.
4. Test the assigned GitHub Pages address before connecting a custom domain.
5. For your domain, configure the **Custom domain** in GitHub Pages and set the corresponding DNS records at your domain registrar. Enable HTTPS once the domain resolves.

**Note:** Committing the website does not automatically connect the custom domain or enable GitHub Pages.
